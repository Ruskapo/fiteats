# FitEats

> SPA-приложение для планирования питания и отслеживания КБЖУ.  
> Пользователь может выбирать рецепты, добавлять их в рацион, сохранять избранные блюда и просматривать подробную информацию о каждом рецепте.

---

## Возможности

- **Просмотр списка рецептов**
- **Поиск рецептов**
- **Добавление рецептов в рацион**
- **Добавление в избранное**
- **Страница подробного рецепта**
- **Модальное окно выбора приёма пищи**
- **Empty State для избранного**
- **Анимации интерфейса**
- **Адаптивная сетка карточек**

---

## Технологии

- React
- TypeScript
- Redux Toolkit
- React Router
- SCSS / CSS Modules
- Framer Motion
- React Hooks

---

## Архитектура

- Feature-подход к организации Redux-слайсов
- Управление состоянием через Redux Toolkit
- Использование типизированных хуков (`useAppSelector`, `useAppDispatch`)
- Разделение UI компонентов и бизнес-логики
- Компонентная архитектура
- Модульные стили через CSS Modules
